# Changelog

## Housing v3 — 2026-10-29
- **Released.** Housing v2 plus a **microSD slot** on the long side (split tongue like the USB-C port, card stands
  about 2.5 mm proud when ejected) and printed **RESET / BOOT** flexure buttons in the base. Printed and test-fitted.
- Button tongues are 1.2 mm thick, matching housing v4, for a firmer press.
- Same outer size, screws, inserts and light pipe as v2. Files in `housings/v3/` (`CYD_Case_v3_*`, STL + STEP).
- Build guide and BOM now cover v2 and v3. v2 is unchanged.

## Docs — 2026-10-29
- The docs site now wears the shared WOODWERD docs theme ([WOODWERD/ctrl-docs-theme](https://github.com/WOODWERD/ctrl-docs-theme)):
  WOODWERD Design mark, ink header with an amber rule, warm cream pages, Inter and JetBrains Mono, and a strip
  linking the Ctrl family. Docs build pinned to MkDocs 1.6 and Material 9.7.7.

## 2026-10-23: repository created
- The housing moves out of the Flow Ctrl repository into its own home, shared by every WOODWERD CYD firmware.
- **Housing v2** (released 2026-09-16, unchanged geometry): files renamed from `CYD_FlowCtrl_*` to `CYD_Case_v2_*`.
- Build guide and BOM reworded for any firmware; compatibility table added.
